# ADR-000: Architecture Decision Records

- **Status:** Accepted
- **Date:** 2026-08-05

## Purpose

This directory contains the Architecture Decision Records (ADRs) for the Onion Wallet project.

An ADR captures a significant architectural decision, including its context, rationale and consequences.

## Format

This project follows the ADR methodology described by Michael Nygard and the ADR community.

- Architecture Decision Records:
  https://github.com/joelparkerhenderson/architecture-decision-record

## ADR Lifecycle

An ADR may have one of the following statuses:

- Proposed
- Accepted
- Superseded
- Deprecated

## Naming Convention

```text
ADR-XXX-short-title.md
```

Examples:

- ADR-001-use-react-for-the-frontend.md
- ADR-002-use-django-for-the-backend.md

## Template

Each ADR should include:

- Status
- Date
- Context
- Decision
- Rationale
- Consequences
