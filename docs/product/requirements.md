# Product Requirements

## Overview

Onion Wallet is a personal finance application that helps users manage their financial activity by tracking accounts, transactions, budgets and financial goals.

## Goals

The main goals of the application are:

- Allow users to track their income and expenses.
- Provide an overview of their financial situation.
- Help users understand their spending habits.
- Provide a foundation for future financial management features.

## Target Users

The application is designed for users who want to manage their personal finances digitally.

## Functional Requirements

## Authentication

The system should allow users to:

- Create an account.
- Log in and log out.
- Manage their profile.
- Recover their password.

## Accounts

Users should be able to:

- Create financial accounts.
- View account balances.
- Update account information.
- Delete accounts.

## Transactions

Users should be able to:

- Create transactions.
- Edit transactions.
- Delete transactions.
- Categorize transactions.
- View transaction history.
- Filter transactions.

## Dashboard

The system should provide:

- Current balance overview.
- Income and expense summaries.
- Recent transactions.
- Spending insights.

## Budgets

Users should be able to:

- Create budgets.
- Define spending limits.
- Track progress against budgets.

## Financial Goals

Users should be able to:

- Create savings goals.
- Track progress.
- Update goals.

## Non-Functional Requirements

### Security

The application should:

- Protect user data.
- Authenticate users securely.
- Validate user input.

### Performance

The application should:

- Provide responsive interactions.
- Handle normal user workloads efficiently.

### Maintainability

The application should:

- Have a modular architecture.
- Include documentation.
- Include automated tests.
